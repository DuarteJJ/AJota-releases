# AJota — downloads

Instaladores do **AJota**: compartilhamento de tela (com áudio) e câmera entre amigos, sem voz e sem captar o áudio do Discord.

**Baixe a versão mais nova em [Releases](../../releases/latest)** → arquivo `AJota-Setup-x.y.z.exe`.

- Dois cliques para instalar. Se o Windows avisar: *Mais informações → Executar assim mesmo*.
- Na primeira vez, cole o código de convite que você recebeu.
- Depois disso o app se atualiza sozinho.

Requer Windows 10 (versão 2004) ou mais recente.
